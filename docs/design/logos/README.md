Each folder has `mark.svg` (the symbol), `logo-light.svg` and `logo-dark.svg` (symbol + name, for light and dark
backgrounds), and a transparent PNG of each (marks 512 px, logos 4×). `letzeuspost/mark-ink.svg` is the reversed mark.
`sheet.png` shows them all together.

**Fonts:** Inter, Baloo Da 2, Hind Siliguri, Anton and Manrope are free Google Fonts (SIL Open Font License). The SVG
wordmarks use live text that loads those fonts, so open them in a browser; the PNGs were rendered with Chrome, which
shapes the Bangla correctly. When a logo is approved, its text gets converted to outlines (that needs a font tool,
installed only with Zeus's OK).

**Colors:** LetZeusPost gold `#F5B301` with ink `#1C1A17` (gold is a fill only; see Section 5's contrast finding) ·
Golpo `#1F5C45` / `#FFB627` / `#FFF1D6` · Ironline `#121212` / `#FF4D2E` (`#C9381E` for small text on white) ·
Brightwell `#0F766E` / `#0F3D3A` / `#CCF0EA`.
